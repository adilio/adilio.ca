Self-contained, curl-able sizing scripts for cloud resource discovery—one shell script per cloud.

Open the provider's cloud shell, paste one command, and start sizing. There is no install, module, or build step; each script uses only the tools already available in Azure, AWS, or Google Cloud shells.
