Scope: `/projects/` index and individual `/projects/:slug/` detail pages. Visitor mode: Experience.

Audience and job: prospective collaborators and employers evaluating breadth and craft, and fellow builders exploring useful work, weighted equally. Visitors should understand the range quickly, inspect a defining project, and still be able to scan the complete catalog.

Content and proof: real project screenshots, concise authored descriptions, individual project stories, external product links, source links, and scheduled GitHub metadata. Curated entries take precedence over generated summaries.

Direction: a project corridor—an oversized scroll-snap exhibition rail followed by a compact filterable workbench index. The memorable moment is seeing the next project visibly waiting beyond the current frame.

Constraints: Hugo and PaperMod; no new runtime dependencies; minimal vanilla JavaScript; keyboard, touch, reduced-motion, light/dark/system, and responsive support.

Unresolved: which future non-4dl projects deserve curated screenshots and pinned placement remains an editorial choice.
